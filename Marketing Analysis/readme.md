# 📊 Marketing Campaign Performance Analysis
## Overview

This project analyzes user engagement across multiple marketing campaigns for an e-commerce platform.

The primary business objective was to identify overall marketing campaign trends and determine whether users spend more time on the website during specific weekdays. The analysis compares session duration, user engagement, conversion behavior, bounce rates, and revenue performance across different marketing campaigns.

The findings are presented through SQL-based analysis and an interactive Tableau dashboard that allows stakeholders to explore campaign performance and user behavior patterns.
