# Product Analysis Project

## Project Overview

This project was created to analyze customer purchasing behavior and understand how long it takes users to complete a purchase after arriving on the website.

The analysis was performed using SQL and Tableau to identify trends in customer engagement, purchasing patterns, and revenue generation.

---

## Business Task

The Product Manager requested an analysis to determine:

> How much time does it take for a user to make a purchase after first arriving on the website on a given day?

The goal was to:
- Identify the duration between a user’s first website visit and their first purchase on the same day
- Track the daily progression of purchase duration
- Better understand customer conversion behavior

---

## Dataset & Analysis

The project uses event-level website interaction data to:
- Track user sessions
- Identify first page visits
- Detect purchase events
- Calculate time differences between arrival and purchase

The final analysis calculates:
- First visit timestamp per user per day
- First purchase timestamp per user per day
- Duration between first interaction and purchase
- Daily average purchase duration trends

## Key Insights

Some important insights discovered during the analysis include:

- Users spend an average of approximately **79 minutes** between their first website interaction and purchase.
- Average order value is around **$65**.
- User engagement increases significantly during the pre-Christmas shopping period.
- Purchase behavior varies across different product categories and countries.
